# 🌑 VANTABLACK: The Ultimate Arsenal (Industrial Edition)

The project has been reorganized following **VANTABLACK Clean Architecture** to hide technical complexity and make room for raw power.

## 📂 Industrial Architecture
- `engines/`: Go engines (Evilginx & Gophish) - The beating heart of the system.
- `bin/`: High-performance compiled binaries.
- `configs/`: Centralization of settings.
- `vanta/`: The internal nervous system (Polymorph Core).
- `vanta.py`: Universal entry point.

## 🚀 Quick Start

### 1. Environment
Ensure you are in the virtual environment:
```bash
source venv/bin/activate
```

### 2. Deployment
Simply launch the interface. If engines are missing, the system will **automatically rebuild them**.
```bash
sudo python3 vanta.py --stealth-level 3
```

# For legacy standalone use:
# python3 vanta_legacy.py

## 🛠️ Integrated Modules
- **Total Deployment**: Launches Gophish and Evilginx with active surveillance.
- **Security Shield**: Immediate audit of the local infrastructure.
- **Self-Healing**: Reconstruction of vital components.
